# Synthetic data dictionary

Every observation used by this pipeline is generated by `synthetic_data.py`.
The public MIMIC demo CSVs are separate reference data, not the source of these variables.
Units below describe the simulator's intended scale, not validated clinical measurements.
No real four-hour aggregation, norepinephrine conversion or 90-day follow-up is performed.

## Identifiers and timing

- `subject_id`, `hadm_id`, `icustay_id`: generated patient, admission and ICU episode identifiers.
- `step`: consecutive simulated four-hour index starting at zero.
- `died`: one simulated binary terminal outcome per ICU episode; no measured follow-up horizon.
- `dataset_split`: train, val or test, assigned by patient.
- State variables are observed before current treatment. Current actions update pressure and cumulative balance for the next observation.

## Thirty state features

| Features | Intended scale |
|---|---|
| age | years, clipped 18–90 |
| gender | simulated binary category 0/1 |
| elixhauser, sofa_initial, gcs | simulated score-like values, not scores calculated from clinical records |
| hr | beats/min |
| sys_bp, dia_bp, map | mmHg; MAP = (systolic + 2 x diastolic) / 3 |
| rr | breaths/min |
| temp | Celsius |
| spo2 | percent |
| fio2 | fraction |
| lactate | mmol/L |
| creatinine, bilirubin, bun, glucose | mg/dL |
| platelets, wbc | 10^9/L |
| potassium, sodium, chloride, bicarbonate | mmol/L |
| ph | unitless |
| pao2, paco2 | mmHg |
| hemoglobin | g/dL |
| urine_output | mL per simulated interval |
| cumulated_balance | mL, balance accumulated before current action |

Missing values are filled with training medians and features standardized using training statistics.
Feature names are exported in `artifacts/features_schema.json`.

## Actions

`iv_fluids` is a simulated fluid amount in mL per interval; `vasopressors` is a simulated
rate on an intended mcg/kg/min scale, not a conversion of real medication records.
Zero is bin 0. Positive training doses are split at their 25th, 50th and 75th percentiles
into bins 1–4. Repeated quantiles can leave empty bins. With no positive training doses,
positive-bin cutoffs remain zero; unseen positive values map to bin 4 without empirical support.
Action ID = fluid_bin * 5 + vaso_bin, from 0 to 24.

## Trajectory columns

Each row contains `subject_id`, `hadm_id`, `icustay_id`, `time_step`, `state`,
`action`, `iv_fluids`, `vasopressors`, `next_state`, `reward`, `done`,
`outcome_type`, `dataset_split` and `died`.
Health states are 0–74; terminal states are 75 (simulated survival) and 76 (simulated death).
Intermediate reward is zero; the final transition receives +100 or -100.
Terminal continuation value is zero. Discount gamma is 0.99 by default.
A return is not a survival percentage or clinical treatment-effect estimate.
